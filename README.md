# 🤖 Dota 2 Telegram Bot & Parser

Автоматизированный бот для сбора новостей и аналитики по Dota 2. 
Демонстрирует навыки работы с API, парсинга данных и автоматизации рутины на Python.

## 🛠 Стек технологий
- **Python 3.10+**
- **aiogram** — фреймворк для Telegram-бота
- **requests / BeautifulSoup** — для парсинга веб-страниц
- **AI-assisted development** — прототипирование и генерация кода с помощью LLM
